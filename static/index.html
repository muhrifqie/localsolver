LOCAL-FIRST CAPTCHA SOLVER

Solve captchas on your own machine.

A FastAPI service backed by a camoufox stealth-browser pool. Tries to solve in-browser first (free), and only falls back to a paid API when you enable it. Everything runs on localhost.

Auto-refreshes every 3s from /health. Returns 429 when the pool is full — raise THREAD × PAGE_COUNT for more concurrency.

Endpoints

Async flow: submit → 202 {task_id} → poll /result?id=… until 200 success · 422 solve-fail · 408 timeout · 404 expired.

Quickstart

# first run: venv + deps + fetch camoufox browser
cd C:\BOT\localsolver
.\run.ps1

# submit a Turnstile solve
curl "http://127.0.0.1:5033/turnstile?url=https://target/&sitekey=0x4AAA..."
# -> {"task_id":"abc...","status":"accepted"}

# poll until done
curl "http://127.0.0.1:5033/result?id=abc..."
# -> {"status":"success","value":"<token>","source":"local","elapsed_time":1.9}
Turnstile note: inject the token into input[name=cf-turnstile-response] and call the widget's data-callback, or the target form rejects it.

Configuration

HEADLESS
true · set false to watch the browser while debugging
THREAD × PAGE_COUNT
concurrency (browser contexts × pages)
SOLVE_TIMEOUT
per-task hard cap, seconds
PROXY_SUPPORT
read proxies.txt, one per context (rotating)
FALLBACK_ENABLED
CapSolver fallback on local fail — needs CAPSOLVER_API_KEY
All knobs live in .env (see .env.example).

Debug & docs

When a solve fails: read the log first (full stack, backtrace on), then rerun one request with HEADLESS=false and match the symptom to the error table in NOTES.md.
